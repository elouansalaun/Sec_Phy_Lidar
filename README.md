
## Choix méthodologique


La végétation (classes 3 à 5 en temps normal) n'est pas séparée. Elle est mélangée dans la classe 1 avec les poteaux, les fils, les voitures et les clôtures.

Conséquence pour l'étape 1.3 : tu dois identifier toi-même la végétation dans la classe 1. Je te propose deux niveaux :

Règles simples : points de classe 1 à plus de 0,5 m au-dessus du sol, hors bâtiments, en utilisant le nombre de retours. La végétation produit souvent plusieurs retours par impulsion, contrairement à un toit ou un poteau.
Plus tard, en option : un petit classifieur (forêt aléatoire) sur des descripteurs géométriques locaux (linéarité, planéité, dispersion) et la couleur RGB. Tu aurais ainsi un deuxième usage justifié du ML dans le projet.
